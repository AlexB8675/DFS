# DFS — Discord File System

A private cloud drive that stores encrypted file chunks as Discord attachments and
keeps the real file system in PostgreSQL. See [docs/DESIGN.md](docs/DESIGN.md) for
the full design.

**Status:** the web UI is being built first, against an in-browser mock API (D14).
The API service, bot and database come next (milestones in §18).

## Requirements

- Node.js 24
- pnpm 10, via Corepack (if `pnpm` is not on your PATH, prefix commands with `corepack`)

## Getting started

```bash
corepack pnpm install
corepack pnpm dev
```

Open http://localhost:5173 and choose **Continue with Discord**. In development the
sign-in is simulated and all data lives in your browser (reset it from the account
menu).

## Scripts

Run from the repository root; Turborepo runs them in every package.

| Command          | What it does                               |
| ---------------- | ------------------------------------------ |
| `pnpm dev`       | Starts the web app with the mock API       |
| `pnpm build`     | Production build                           |
| `pnpm typecheck` | TypeScript checks                          |
| `pnpm lint`      | ESLint, including the React Compiler rules |
| `pnpm test`      | Unit tests (Vitest)                        |
| `pnpm format`    | Formats with Prettier                      |

## Layout

```
apps/web          React SPA (React 19 + React Compiler, Vite, Tailwind, shadcn/ui)
  src/app         router, query client, providers
  src/features    one folder per feature: auth, drive, tree, uploads, trash, shares, …
  src/layout      app shell: header, sidebar
  src/components  shared components; ui/ is generated by shadcn
  src/mocks       mock API (MSW) and demo data, dev only
packages/shared   API schemas (Zod) and file-name rules, shared with the future API
docs/DESIGN.md    design document
```
